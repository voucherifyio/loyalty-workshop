# Contributing

Thank you for your interest in contributing to Loyalty Workshop!

## Before You Start

1. **Read [STYLE_GUIDE.md](STYLE_GUIDE.md)** — All coding standards and patterns *(required)*
2. **Review [DEVELOPMENT.md](DEVELOPMENT.md)** — Setup, workflow, common tasks
3. **Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)** — Community guidelines

## Workflow

1. Fork the repository and create a feature branch
2. Make your changes following the style guide
3. Run `npm run lint` — All code must pass linting
4. Run `npm run build` — Ensure no compilation errors
5. Open a pull request with clear description

## Reporting Issues

Use the appropriate issue template:
- [Bug Report](https://github.com/voucherifyio/loyalty-workshop/issues/new?template=bug_report.md)
- [Feature Request](https://github.com/voucherifyio/loyalty-workshop/issues/new?template=feature_request.md)
- [Question](https://github.com/voucherifyio/loyalty-workshop/issues/new?template=question.md)
